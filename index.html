Configure o banco de dados uma vez — depois toda a equipe compartilha os mesmos dados, sem depender do Claude.

1

Crie uma conta gratuita no Supabase

Acesse supabase.com → Start your project → crie um projeto. Escolha qualquer nome e guarde a senha do banco.

2

Crie a tabela — cole e execute no SQL Editor

No painel do Supabase, vá em SQL Editor e execute:

create table if not exists imob_dados ( id int primary key default 1, payload jsonb not null default '{"imoveis":[],"nextId":1,"dismissedAlerts":[]}'::jsonb, updated_at timestamptz default now() ); insert into imob_dados (id, payload) values (1, '{"imoveis":[],"nextId":1,"dismissedAlerts":[]}') on conflict (id) do nothing; alter table imob_dados enable row level security; create policy "equipe" on imob_dados for all using (true) with check (true);

Clique em Run. Deve aparecer "Success".

3

Copie as credenciais

No painel do Supabase vá em Project Settings → API e copie:
• Project URL (começa com https://)
• anon / public key (chave longa)
